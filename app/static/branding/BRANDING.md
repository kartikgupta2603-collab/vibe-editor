# Vibe Editor branding

Approved design: the exact black-on-white VIBE EDITOR image supplied by the user on 2026-10-18 (`codex-clipboard-ad6313e1-6b6a-46ce-ba37-9c950460697c.png`). The original upload is preserved byte for byte. No generated companion symbol is used.

## Assets

- `vibe-editor-approved.png`: original selected logo.
- `vibe-editor-logo.png`: approved wordmark with outer blank margins trimmed for the UI.
- `vibe-editor-icon-master.png`: the same complete wordmark centered on a white square; no elements redrawn or removed.
- `vibe-editor-icon-192.png`, `vibe-editor-icon-512.png`: web/app icons.
- `apple-touch-icon.png`: 180px bookmark/home-screen icon.
- `../favicon.ico`: 16–256px browser icon.
- `../site.webmanifest`: app name, colors and icon references.

UI wordmark removes only the outer blank margins. Icons are resized copies of the complete logo, preserving its proportions and white background.

## Placement

Studio navigation, empty Studio welcome, Settings, Brush Animator header and browser/app metadata. Branding is an interface layer and is not added to exported videos. There is no login page in the current app.
